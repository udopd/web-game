# Работа с Content Studio

Откройте `/editor`, введите ADMIN_EDITOR_TOKEN. Публичная игровая сессия не даёт доступа к редактору. API, статические JS/CSS редактора и приватные ассеты проверяют административную сессию.

Выберите проект в верхней панели. Библиотека слева объединяет 36 коллекций в 17 групп. Поиск работает по имени и ID; кнопка `+` создаёт определение с исходными значениями схемы. Инспектор редактирует реальные поля, ссылки, массивы и варианты union. После создания обязательно заполните ссылки и выполните проверку.

Изменения автоматически сохраняются через 1,2 секунды. Undo/Redo доступны кнопками и Ctrl+Z/Ctrl+Shift+Z; Ctrl+S сохраняет. История локальна для вкладки. Duplicate создаёт новый ID; Delete требует подтверждения. Удаление используемой сущности обнаруживает валидатор.

Панели можно перетаскивать между группами Dockview, отделять и разворачивать. Пресеты Combat/Art/Level/Logic меняют компоновку. Макет сохраняется в metadata проекта и не попадает в runtime ZIP.

SimulationWorkbench выполняет общую симуляцию: seed, campaign, запуск/пауза, один tick, reset и collision overlay. После изменения данных пометка STALE означает, что нужно нажать «Применить». Выбор оружия, персонажа или мутации настраивает этот preview. Просмотр sprite, animation timeline, аудиофайла и кривых доступен в панели Preview. Все специализированные preview-сцены из ТЗ пока не реализованы.

Для графов выберите effect graph или campaign и откройте Event Logic. Узлы/рёбра меняют runtime данные, координаты узлов — только metadata. Для тайлмапов выберите tilemap и откройте Level. [Уровни](LEVEL_EDITOR_GUIDE.md) описывают инструменты.

Asset Manager принимает несколько файлов через выбор или drag-and-drop. Загрузка последовательная, сервер проверяет реальные PNG/WebP/OGG/MP3/WAV, размеры, длительность и SHA-256. Загруженный ресурс можно связать с новым определением. Resume/chunk upload и пакетная привязка кадров ещё не поддержаны.

Validate показывает пути ошибок. Export ZIP формирует настоящий pack с manifest. Import ZIP валидирует архив и защищает существующие immutable asset paths от замены другими байтами. Publish требует нового номера версии и текущей revision. Versions позволяет переключить активную опубликованную версию. Черновик и расположение панелей при rollback не меняются.
