## 5. Edge cases

- Нет допустимой цели;
- Цель умерла между событием и применением команды;
- Игрок умер или отключился;
- Истек cooldown;
- Два эффекта сработали одновременно;
- В кооперативе одна цель принадлежит другой команде;
- Эффект убивает цель и сам генерирует новые события;
- Save/Load посреди эффекта;
- Новый патч контента при продолжающемся забеге.

## 6. Инструкция ИИ (вставить вместе с карточкой)

Изучи `CUSTOM_MUTATION_PIPELINE.md`, API в `packages/mutation-sdk/`, текущие handlers, JSON Schema и структуру редактора. Реализуй запрошенную мутацию с минимальными изменениями. Сначала докажи, почему достаточно builtin/graph или почему необходим custom extension. Не меняй основное ядро без объективной причины; не добавляй проверки конкретного mutation ID. Если нужен новый тип, создай собственную папку расширения: `extension.json`, `params.schema.json`, `editor.schema.json`, `handler.ts`, `handler.test.ts`, `README.md`. Используй только разрешенный контекст, детерминированные команды, лимиты событий и сериализуемый state. Добавь конфигурацию в `mutations.json` и `effect-definitions.json` через предусмотренный редакторский workflow; подключи assets по ссылкам на ID. Не помещай исполняемый код в ZIP. Проверь регистрацию, UI Inspector, Test Arena, контент-валидацию, серверный multiplayer, replay, Save/Load. Если тест выполнить нельзя — объясни конкретную причину и не утверждай, что он пройден. Предоставь diff по измененным файлам, список тестов, результат и инструкции по публикации.

## 8. Дополнительные SFX/VFX параметры (необязательные)

При создании мутации ИИ должен проверить необходимость эффектов и использовать [`AUDIO_PARTICLES_SETTINGS_PIPELINE.md`](./AUDIO_PARTICLES_SETTINGS_PIPELINE.md):

- `soundId`: существующий ID или создать новый SFX через защищенный Sound Library.
- `particleEffectId`: существующий ID или создать новый эмиттер через Particle Lab.
- `cameraEffectId`: ID необязательного shake preset.
- `presentationTrigger`: семантическое событие из каталога (например, `mutation.activated`).
- `conditions`: только разрешенные типизированные операторы.

Мутация не должна менять геймплей из-за того, что звук/частицы отключены. Включить в тесты проверку целостности ссылок и импорт → экспорт → импорт.


## 9. Контекст новых событий мира (если относится к мутации)

При постановке задачи ИИ явно укажи, должна ли мутация реагировать на `prop.destroyed`, `chest.opened`, `enemy.killed`, `boss.killed`, `loot.picked_up`; нужен ли типизированный параметр `difficultyRating`, привязка к дропу или SFX/VFX/camera preset. Руководствуйся [`WORLD_CONTENT_AND_UNLOCKS_PIPELINE.md`](./WORLD_CONTENT_AND_UNLOCKS_PIPELINE.md). Никогда не позволяй клиентскому коду мутации открывать персонажей, изменять статистику/лут напрямую или обходить server-authoritative runtime.
